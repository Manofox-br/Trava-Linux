## 📝 Como executar:
### -> Abra seu terminal (normalmente o atalho será `CTRL` + `ALT` + `T`):
Execute este comando para baixar o projeto, ou baixe manualmente.
```bash
  git clone https://www.github.com/Manofox-br/Trava-Linux.git
```

### -> Ainda no terminal:
Rode o arquivo ``main.py`` para inciar o teste de desempenho, use o comando abaixo.
```python
  python -m main
```

---

## 📚 Requisitos
1. Executar em uma distribuição Linux;
2. Ter o python instala (caso não tenha, clique [aqui]() e instale);
3. Opcional, mas ajuda na instalação do repositório. Tenha a blibioteca `git` instalada, use o comando ``sudo apt install`` para isso.

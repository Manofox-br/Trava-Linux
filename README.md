### -> Abra seu terminal (normalmente o atalho será `CTRL` + `ALT` + `T`):
Execute este comando para baixar o projeto
```bash

```

### -> Ainda no terminal:
Rode o arquivo ``main.py`` para inciar o teste de desempenho, use o comando abaixo
```python
  python -m main
```
